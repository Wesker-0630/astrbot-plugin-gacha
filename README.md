# 抽老婆插件 - README

> 
> AstrBot 抽老婆卡牌插件，支持抽卡、收集、图鉴、兑换、抢夺功能

## ✨ 功能简介

- 抽卡：每日最多 3 次随机抽取角色，附带磨损标签（崭新出厂 / 略有磨损 / 久经沙场）
- 个人图鉴 `/我的老婆`：分页大图展示自己收集的角色，每页 16 个，4 列布局
- 全卡池总览 `/老婆池列表`：一次性生成**全部角色超长图鉴大图**，未收集角色自动灰度变暗
- 角色查询 `/查看老婆`：输入角色 ID 或者角色名称模糊检索，查看角色原图、个人持有数量、全服拥有人数
- 收集进度 `/老婆进度`：生成进度图片，统计已收集 / 全部角色数量与收集率
- 角色兑换 `/兑换老婆`：消耗 3 张同角色，兑换一个自己尚未拥有的角色
- 抢夺玩法 `/抢夺老婆`：输入用户 ID 尝试抢夺对方角色，每日 1 次，成功率 30%
- 管理员后台：添加 / 删除角色、一键清空**全部用户存档记录**（卡池角色不会删除）

## 📁 文件结构

```
your_plugin_folder/
├── main.py                # 插件主代码
├── wives.json             # 角色卡池配置（角色ID、名称、图片路径）
├── assets/                # 存放角色本地图片
│   └── xxx.png
└── data/
    └── user_data.json     # 用户存档：每个人收集记录、每日抽卡/抢夺次数
```

## 📦 安装部署

1. 将整个插件文件夹放到 AstrBot 插件目录
2. 在`wives.json`添加角色信息，格式示例：

```
[
    {"id": 1, "name": "角色A", "img": "a.png"},
    {"id": 2, "name": "角色B", "img": "b.png"}
]
```

> 
> `img`字段支持：本地图片文件名（放在 assets 目录），或者 https 网络图片链接

3. 本地图片放到插件内的`assets`文件夹
4. 重启 AstrBot，插件自动加载

## 📖 指令列表

### 普通用户可用

表格

| 指令 | 说明 |
| --- | --- |
| `/抽老婆` | 抽卡，每日最多 3 次，随机获得角色，附带磨损标签 |
| `/查看老婆 [ID/角色名]` | 通过 ID 或名字查找角色，展示原图、个人持有、全服拥有人数 |
| `/我的老婆 [页码]` | 个人收藏图鉴大图，每页 16 个角色；默认第 1 页，例 `/我的老婆 2` |
| `/收集进度` | 查看收集进度图片，统计收集数量 |
| `/图鉴` | 生成全部角色超长总览大图，已收集正常显示，未收集灰度变暗 |
| `/兑换老婆 [ID]` | 消耗 3 张相同角色，兑换 1 张未拥有角色 |
| `/ntr [对方用户ID]` | 尝试抢夺目标用户角色，每日 1 次，成功率 30% |
| `/老婆帮助` | 查看全部指令帮助 |

### 管理员专用指令

表格

| 指令 | 说明 |
| --- | --- |
| `/添加老婆 [角色名] [图片文件名]` | 新增角色到卡池，自动分配 ID |
| `/删除老婆 [ID]` | 删除卡池中指定 ID 角色 |
| `/重置全部老婆记录` | **一键清空所有用户存档**，只删除用户收集记录，保留 wives.json 卡池角色 |

## ⚠️ 重要注意事项

1. **数据备份**
用户所有收集记录保存在 `data/user_data.json`，执行重置指令或手动删除文件前建议备份，删除后记录无法恢复。
2. 图片压缩
生成图鉴大图默认 JPEG quality=85 压缩，降低图片体积。
缩略图尺寸配置（main.py 头部）
```
THUMB_W = 200
THUMB_H = 260
```

如果图片过大，可以调小这两个值。
3. 字体问题
优先使用`simhei.ttf`黑体；找不到黑体会自动使用系统默认字体，可能出现文字错位。
4. 名称检索规则
`/查看老婆` 名称检索为**模糊匹配**，关键词包含在角色名即可；多个匹配结果只会返回第一个命中角色。

## 🛠 重置所有用户存档两种方式

1. 指令一键重置（管理员）

```
/重置全部老婆记录
```

2. 手动重置
关闭 AstrBot，删除 `data/user_data.json`，重启 AstrBot，插件自动生成空存档文件。
