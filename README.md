# 抽老婆插件（AstrBot）

一个基于 AstrBot 框架的趣味抽卡收集插件。通过 `/抽老婆` 随机抽取角色卡，收集你的 "老婆" 图鉴，支持兑换、抢夺（NTR）、进度统计，并自动生成漂亮的网格大图。

## 功能特性

- 🎰 **每日抽卡**：每天最多 3 次，随机抽取卡池角色，包含 3 种磨损品质（崭新出厂 / 略有磨损 / 久经沙场）
- 📖 **老婆图鉴**：一次性生成全部角色超长总览大图（每行 10 个，未拥有角色自动灰化）
- 🗂️ **我的老婆**：分页网格查看个人收藏（每页 16 个、4 列、缩略图 500×500），自动生成大图
- 🔍 **查看老婆**：支持按 ID 或角色名称模糊搜索，显示持有数量与全服拥有该角色的人数
- 📊 **收集进度**：生成进度表格图片，显示已收集 / 总数 / 收集率
- 🔄 **兑换老婆**：消耗 3 张相同角色，兑换 1 个未拥有的角色
- 💢 **NTR 抢夺**：随机复制对方一个老婆给自己（**对方不损失**），具体规则见下文
- 👑 **管理员功能**：添加 / 删除角色、清空全服记录

## 目录结构

```
astrobot-plugin-gacha/
├── main.py                 # 插件主代码
├── wives.json              # 卡池角色配置（自动生成）
├── assets/                 # 本地角色图片目录（自动创建）
└── data/                   # 用户存档目录（自动创建）
    ├── user_data.json      # 用户收集记录
    └── *_tmp.png           # 临时生成的图片文件
```

## 安装

1. 将插件文件夹放到 AstrBot 的 `plugins` 目录
2. 首次启动自动创建 `assets/`、`data/` 目录和 `wives.json` 空配置
3. 在 `wives.json` 中添加角色（见下方配置说明），或通过管理员指令 `/添加老婆` 添加
4. 在 AstrBot 管理界面加载 / 重载插件

## 角色配置（wives.json）

```
[
  {
    "id": 1,
    "name": "角色名称",
    "img": "xxx.png"
  },
  {
    "id": 2,
    "name": "角色名称",
    "img": "https://example.com/xxx.jpg"
  }
]
```

- `id`：角色唯一 ID，自动递增
- `name`：角色名称
- `img`：图片，支持**本地文件名**（放在 `assets/` 目录）或**网络图片完整 URL**

## 指令说明

### 玩家指令

表格

| 指令 | 说明 |
| --- | --- |
| `/抽老婆` | 每日最多 3 次抽卡，回复自动 @本人并附带角色图片 |
| `/查看老婆 [ID/角色名]` | 查看角色详情（按 ID 精确、按名称模糊匹配） |
| `/我的老婆 [页码]` | 分页查看收藏网格大图，每页 16 个 |
| `/收集进度` | 查看收集进度统计图 |
| `/老婆图鉴` | 生成全部角色超长总览大图 |
| `/兑换老婆 [ID]` | 消耗 3 张相同角色兑换 1 个未拥有角色 |
| `/ntr @某人` | 抢夺对方老婆（规则见下） |
| `/老婆帮助` | 查看全部指令说明 |

### 管理员指令

表格

| 指令 | 说明 |
| --- | --- |
| `/添加老婆 [名字] [图片文件名]` | 添加角色（仅管理员） |
| `/删除老婆 [ID]` | 删除角色（仅管理员） |
| `/重置全部老婆记录` | 清空所有用户的收集、每日抽卡与抢夺记录（卡池保留） |

## NTR 规则（当前版本）

1. **发起条件**：`/ntr` 后必须 `@` 一个目标用户，且不能对自己使用
2. **每日 1 次尝试**：NTR **失败后当天锁定**（提示 "黄毛被干掉"），次日重置
3. **成功后继续**：NTR **成功后不锁定**，当天可继续抢夺其他目标
4. **结果逻辑**：成功即**随机复制**对方一个老婆给你，**对方的老婆不会减少**（复制而非夺走）
5. 成功率默认 40%，可在代码 `success_rate = 0.4` 调整

## 配置项（main.py 顶部）

```
MY_WIFE_PAGE_SIZE = 16    # 我的老婆每页角色数
MY_WIFE_GRID_COLS = 4     # 我的老婆每行列数
POOL_GRID_COLS = 10       # 老婆图鉴每行列数
MY_WIFE_TEXT_HEIGHT = 50  # 我的老婆文字区高度
THUMB_W = 100             # 老婆图鉴缩略图宽
THUMB_H = 100             # 老婆图鉴缩略图高
TEXT_HEIGHT = 20          # 老婆图鉴底部文字区高度
GOLD_COLOR = "#ffd700"    # 金色边框
```

> 
> 「我的老婆」大图缩略图固定为 500×500（函数内 `GRID_THUMB_W/H`），底部文字字号 20；「老婆图鉴」缩略图 100×100、文字字号 14，二者独立设置互不影响。

## 数据存储

- 所有数据保存在 `data/user_data.json`
- 每个用户记录结构：

```
{
  "用户ID": {
    "wives": { "角色ID": 持有数量 },
    "daily_draw": 0,
    "last_draw_date": "",
    "rob_used": false,
    "last_rob_date": "",
    "ntr_fail_date": ""
  }
}
```

- 每日抽卡次数、NTR 锁定均按日期自动重置

## 注意事项

- 图片读取失败时会显示 "图片缺失" 占位，不影响其他角色
- 生成的大图为 JPEG 压缩保存，降低体积便于 QQ 发送
- 当前适配 AstrBot v4.28.2（NapCat），消息链中 @ 组件使用 `Comp.At(qq=xxx)` 写法
